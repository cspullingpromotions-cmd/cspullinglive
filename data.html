vMix Setup Instructions
1. In vMix, go to Add Input → Web Browser
2. Enter the Active Class URL above
3. Use Data Sources in vMix to map fields:
   • active_class.results[0].driver_name → Driver name overlay
   • active_class.results[0].distance → Distance overlay
   • active_class.results[0].place → Position overlay
   • active_class.leader.driver_name → Leader lower-third
   • active_class.leader.distance → Leader distance
4. Set refresh rate to 3000ms (3 seconds)
